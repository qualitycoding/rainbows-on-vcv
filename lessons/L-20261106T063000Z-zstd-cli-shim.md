## Trigger
`make dist` failed with `zstd: not found`; the host had libzstd but no CLI, and
package installation was unavailable.
## What went wrong
Assumed a zstd CLI would exist wherever libzstd-dev is installed.
## Correction
Compiled a minimal stdin->stdout zstd compressor against the system
libzstd, staged it on /tmp (durable mount is non-executable), prepended to PATH.
## Prevention rule
Before relying on any compression/archival CLI in a build, check `which <tool>`
and, if absent but the library exists, build a tiny shim on executable storage.
## Detection check
`echo test | <shim> -3 -o t.zst` produces a file with the zstd magic
`28 b5 2f fd`, and `make dist` completes.
