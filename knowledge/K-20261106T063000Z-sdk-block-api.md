## Claim
Rack SDK 2.6.6 `engine::Engine` exposes the current block frame count as
`getBlockFrames()` (returns int). There is no `getBlockSize()`; similarly
`getBlockTime()`/`getBlockDuration()` give block timing. Sizing per-block
scratch buffers should use `APP->engine->getBlockFrames()`.
